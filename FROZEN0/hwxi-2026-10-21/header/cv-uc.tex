{\itemfont Doctoral Thesis}    & {\em Dependent Types in Practical Programming} \\
           02/96 to 08/98      &
This work strengthens the current type system of the functional programming language ML with
a restricted form of dependent types. It not only provides the programmer with significantly more
information to catch program errors at compile-time, but also enables the compiler writer to
obtain type information for optimizing code generation. As a significant application, we
have shown how to eliminate array bound checks in realistic programs.
